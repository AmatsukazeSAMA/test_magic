- 本包仍未审定的条件候选：无。这些候选保持独立，不混入已复核裁切清单。

- 字幕前/后层序、遮挡缺笔、投影缺失和同色相接仍按overlay_manifest逐帧metadata处理；这不是恢复作者原alpha。
- 完整未决状态见reuse_manifest，不将未绑定帧自动当新稿，也不自动并到最近参考。
