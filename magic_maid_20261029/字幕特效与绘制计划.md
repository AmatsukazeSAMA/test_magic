本轮重点是**可重新合成的字幕和特效透明素材**，不是修复被遮挡的人物，也没有开始角色重绘。附件1 `source/original.mp4` 是唯一制作像素来源；附件2 `source/reference.mp4` 只用于动作编号、复用和教程提醒。两份原视频、原有 `cels/`、上一版可逆分区全部保留。

## 导出给后期软件

在仓库根目录安装 `requirements-layers.txt` 所列依赖。已下载的 alpha PNG 不依赖全量原片缓存；只有重新提取或原帧对比才需要恢复 `frames/`。

交付ZIP解压后已经是**可直接导入的普通逐帧PNG序列**：字幕分为15个语义S包，每包小于95 MB，**s06黑裙完整舞蹈不再拆成多个镜头包**；特效为单独全片ZIP。特效文件为`effects/F000000.png`至`F004762.png`，共4763张；字幕文件为各包`sXX/subtitles/L000000.png`起的局部序列，15包合计4763张。持帧也保留独立的PNG文件条目，不需要再从素材ID展开。

只有仓库`overlays/subtitles/`和`overlays/effects/`按内容寻址去重存储。以下命令用于自行重建整轨或按S包另行导出；脚本单包导出使用`F000000.png`起的局部编号，与交付字幕ZIP的`L000000.png`命名不同，均以各自JSON/CSV中的局部→原片映射为准。不要将s06等非连续出场片段的局部顺序误作原片连续顺序。实际压缩包、查看视频与文件数量在上方交付清单中列明。

全片两条普通 PNG 序列（输出目录必须不存在）：

```bash
python scripts/magic_maid_overlays.py export-sequence --category both --output magic_maid_20261029/overlay_exports/full
```

只导出一个工作包：

```bash
python scripts/magic_maid_work_sections.py export s06 --output magic_maid_20261029/overlay_exports/s06
```

导出物包括两条 `F000000.png` 起的 PNG 序列、`sequence.json` 和 `*.ffconcat`。全片导出对应原片帧号；单包导出为局部帧号，JSON/CSV 保留其原片位置。**S 包内不连续的出场片段会顺接为工作索引，不代表修改后的成片剪辑。**

时序使用 **1/16000 秒**的原 PTS，末视频帧时长为 **533 ticks**。不要将全部帧强制按 30 fps 排列后称为精确还原；后期软件的固定帧率导入只可作为近似工作视图。精确回合成以 JSON 的逐帧 `pts/duration_ticks` 为准。ffconcat 的最后一个重复文件条目只是尾帧时长哨兵，不是额外原画。原音频尾部比视频略长，应保留而非自动截断。

## Alpha、层序与可用性

1. PNG 使用 **straight alpha**。在后期软件中按“直通/非预乘”解释；若软件需要预乘，先用其正确转换，勿重复预乘造成黑边。
2. 不裁切画布，不重新居中；1920×1080 的坐标与附件1一致。画面缩放或镜头变换是曝光/合成属性，不自动等同于新原稿。
3. 字幕轨包含文字自带的黑/白矩形设计底条；装饰性白框、时钟和背景不冒充文字。主字幕和 FX 不应重复叠加同一底条。
4. 部分大字在人物后方，部分字幕在人物前方；查看逐帧 `metadata` 的层序标注。不能把所有字无脑盖到替换人物上方。已被人物完全挡住且从附件1其他曝光也未见到的笔画不会凭字体重画。
   字幕和特效之间也不是永久固定顺序：例如幽灵常在前景歌词下，而 F3368 的巨星遮在歌词上。查看 `effects.metadata.subtitle_relation`；工作台默认按清单自动排序，也可手动切换“特效在字幕上/下”。混合或不明关系会警示，不能把一次切换套用全片。
5. 花瓣、星芒、幽灵、橙色飞溅和黑色转场的边缘使用估计软 alpha，避免把原背景或手套 RGB 带到新底色。已观测的固定色区域/闭环补足若用到模型推断，会在 metadata 中注明；这不是找回作者工程的原始 alpha。
6. 透明区 RGB 归零；颜色和抗锯齿是针对扁平压缩视频的提取估计。画面中的白对白、同色相接、半透明叠加和压缩噪声可能不可唯一分离，逐帧状态与视觉报告保留限制。
7. 工作台浅底/深底/棋盘格与独立查看视频用于检查边缘污染、缺字、淡入淡出和时序。MP4 查看版本身**没有 alpha**，不能替代交付的 PNG。

### 已知需要人工留意的素材

- **不完整的大字**：人物后方且在附件1其他曝光也没有露出的笔画不补造。M23 手套接触处的「に」、M35 下排「晴／れ」等保留 partial；换角色后如果不再遮住这些地方，需要补字，不应把它们当作完整字体素材。
- **M15短白字卡**：F1908–F1920仍可见的白字已纳入字幕处理；这项修正不表示被遮住或原片从未露出的笔画也已恢复。
- **文字阴影**：M07、M16 交付的是字形本体，原投影未保留；M08 使用原片可观测的阴影等效层，但不是作者原始阴影参数。M30 三组「バイ」用附件1 M33 的同字形补足，经过零缩放／零平移的可见轮廓匹配，未用新字体替代。
- **截出画布的幽灵**：例如 F591 右上幽灵只保留已识别白轮廓，粉色身体缺失，明确不算完整特效。F476／F504 的可观测闭合身体和透明眼孔已修正，二者不要混为一个质量状态。
- **被歌词遮住的特效**：原歌词盖在幽灵、飞溅或放射之上时，FX 轨可能留下歌词／阴影足迹的透明缺口。维持原字幕层序时可用；任意换字幕或让原本被挡处露出，需要局部补足。
- **同色相接**：F2247 胸针金面与橙色放射相接，细小接触区仍有道具混入风险；黑底黑字、面包和星芒同色处也不能保证唯一分离。细微压缩颗粒和低于噪声的淡出另见逐帧 metadata。

这些限制与相应原生大小证据分别记录在 [字幕提取复核](data/SUBTITLE_EXTRACTION_REVIEW.json)、[字幕来源复核](data/SUBTITLE_PROVENANCE_VERIFICATION.json) 和 [特效提取复核](data/effect_overlay_visual_audit.json)。全片映射完成不等于上述区域已经修好；需要后期补足的位置是明确交接项，不隐藏在“通过”结论中。

## 复用证据与未知项

附件2提供复用提示和作者教程文字；是否能复用仍对照附件1的头发、脸、手势、衣纹、坐标和可见轮廓确认。只有重复曝光/几何变换有证据时才建立 canonical 关系；无法证实的 scale/position/crop/mirror 保留未决，不猜测精确矩阵。

`first_observed_exposure`、`reused_visible_drawing`、`unresolved_candidate`、`no_visible_character`、`prop_or_emblem_only`、`occluded_unobservable`明确区分。未决帧不自动算新增原画，也不自动并到最近一张参考图。**302项线稿/局部改线+4项仅校色是当前可执行制作清单，不是宣称完全捕获作者全部原画。** 尚未绑定或遮挡的原片状态仍可能需要补判，旧全片审核和数字校验不能替代新角色完成后的美术验收。
