# 整帧 API 重绘：背面与侧面

本轮按用户“使用 API 整张重绘”和“要完整的卷发段”生成两张静帧。使用已配置 OpenAI API，请求模型 `gpt-image-2.5-sunburst`，质量 `high`，各一次请求、各一张，实际返回均为 **2560×1440**。用户明确同意将所列参考图发送至 `api.openai.com`。

交付图片是解码后的 API 原始返回，与响应图片字节完全一致。没有后续换头、剪贴卷发、补画、调色或放大。`qa/` 中另存的局部图仅用于查看。

背面平背景抽样区（原片坐标 `[700,400,780,600)`）在原片中为单色 RGB `[213,167,169]`；返图对应区域中位数约 `[205,160,162]`，有 41 种 RGB，通道标准差约 0.6。该只读诊断支持“新增轻微纹理/色差”的观察，不作为通用艺术评分。

本轮是整帧生成，字幕、背景、身体都参与重绘，不能当作受像素保护的原片合成层。文字布局肉眼基本延续，但没有完成逐字、逐像素校对。未导出动态，也未评价帧间连续性。

原片负责动作和画法；最初人设及用户新增参考负责身份、bob 和卷发结构。旧的缺辫、短辫或局部拼接候选没有用作本轮 API 底图。
