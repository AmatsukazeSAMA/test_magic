绘制一张 F2599 原PV透明人物层，624×1072。图1自身原片是这帧手势、头颈角度、脸部、双手交叉、衣装、腿脚和可见范围的唯一依据。保帽顶、两手指尖和原两只完整鞋，人物独立透明；粉底、白字和引导框留后期，不画进人物。

F2599 头颌和躯干转向画左的三分之四视角，画右近侧肩更完整；两眼依自身透视，画左眼较窄，画右眼较圆，不把头扭成上一帧的正面；闭口小弧笑。两只手都在画左：上方远手从远侧画左袖口竖起，最高指节弯折向上，其余手指屈折，其中一指向左侧弯出；保源具体指节而非照抄前一帧竖直抬指。近侧画右袖穿过胸腹到画左，近手在下方，摊平并向画左伸，指尖偏左下，原近侧宽白袖口在交叠中挡住远袖一段；两手/两袖不能熔成一体，也不把下手移回画右。保画右黑肩/白褶与腰后两段白带、左偏的围裙、起伏黑裙。画左较低前鞋完整，画右屈腿抬高的斜鞋也完整，踝带与上腿被裙自然遮住的可见范围照源，不裁鞋、不补裙下腿。

换成灰短bob，图2仅灰bob刘海简笔身份。人物自身LEFT根仍在近侧，画右低耳后/bob下缘/颈后，恰好两颗红珠连同一束发。依此帧三分之四透视把灰钻发落在画右近侧肩前、领胸侧；与近侧白肩褶、袖和交叠前臂保持真实前后关系，遮住的段可以隐藏。不挂高侧脑、换边、全卷漂在肩外或穿过前景手衣；不取他帧的根位、头角、手势或卷轴。

图3只供完整构造。单条正常头肩体量宽灰带沿空心轴连续回折，恰好两大转＋一次独立明显较小的真小转，之后才收成渐细短C。每大转有宽灰正面及实体灰后返回，小转也有自己的灰正面与返回；C内洞不算一圈，第二大转不能直接卷成C，也不补第三个等大的主圈或额外圈。实际空处才透明；灰后返回保留，不强挖固定可见孔数。薄荷仅简笔窄边，不画银白亮带、金属渐变、密发丝。图5仅参考首大转正面带面较薄的弧片，保持正常卷径和整体体量，不把整卷缩成小挂件，也不照搬图5其他段、开口、珠饰或肩褶。

图4只参考用户选定B低饱和深灰和底部较柔低反差浅灰弧区，按各自眼轴；不描摹其暗斑、中心瞳点、眼形或高光。眼白、睫线、虹膜轮廓、视线、小白高光都依图1。不添眼下装饰点或痣，保原真实睫线/鼻口。保原简笔粗细起伏黑线和平涂，不向量精修。人物与自身动作先经主评/独审实际过关，两只正常睁眼再另做局部Python B眼内校准；首绘色不当成后审已过。
