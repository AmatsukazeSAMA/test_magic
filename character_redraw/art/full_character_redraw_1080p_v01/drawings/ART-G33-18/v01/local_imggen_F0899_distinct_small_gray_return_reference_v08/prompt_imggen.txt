辫子固定在人物自身的左侧，不是画面左侧；正面通常位于画面右侧。人物转到侧面或背面时，仍保持同一个解剖左侧的低耳后发根，按当前转向和遮挡投影，不能换边或镜像人物。
罗马卷采用最新统一画法：空心，两大卷加一个小卷；宽灰正面与不透明灰返回连续接合，绿色挑染为窄细材料边。按本帧透视、摆动与遮挡绘制，不能加圈、封口成柱、换侧或强挖实体返回。

在这张放大的现有画片里，保留上方两红珠和已经有的两个大灰转，只重画它们下方的末段。画成一个三级结构：第二大转的内缘向下连到一片明显更窄的灰色小转正面；这片小正面斜跨并遮住自己的短灰色内返回边，露出该返回边，画出清楚的翻转叠压；返回边接出一小截短尖向内弯成 C。小转正面、短灰返边和更短的 C 尖都能分别指出。第三小转约大转宽度的一半，最末 C 只约小转宽度的一半。灰色是发带主体，薄荷仅一根窄细边。保留图中白肩褶在发卷后方的遮挡关系，画出干净简笔黑线。输出这个近景画片，画面容纳原有红珠到新 C 尖。不要加入整个人物。
