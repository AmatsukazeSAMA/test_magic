# 1080P 全片人物 API 重绘

按最新要求只绘制人物，成片画布为 1920×1080。人物素材使用紧凑的透明 PNG，API 质量保持 `high`。字幕、特效、背景和独立道具另作后期合成。

最新发型约束：钻发自然垂落，不强制放到肩前；人物自身左侧的发根、双红珠、长度、卷向和遮挡关系随头部转向/翻转连续变化，不固定在画面同一侧。原片决定身体动作和服装，不另造站姿。

当前是**执行中的人物稿候选工程**，不是已验收成片。307 项已编目任务由原清单 306 项加胸针人物肖像 1 项组成。最初1929个未归属曝光已完成归属核查，当前未解决归属数为0；这仅证明曝光分类已核清，不代表307项绘制、自评、实际绑定及全片播放均已完成。当前状态以 `PROGRESS.json` 和逐帧台账为准。

- `REDRAW_PLAN.json`：原片来源、PTS、裁切、尺寸、版本和组内顺序。
- `PROGRESS.json`：实际返图、待审、HOLD 与结果未知的 API 调用；由实际收据重建。
- `drawings/<ID>/<版本>/`：输入、提示词、API 原稿或来源清楚的原图矩形裁片、技术检查和实际视觉评语。
- `batches/`：已尝试的相邻稿共画原始返回；保留动作变化不符合要求的失败证据，不将其当作通过。
- `review/`：原片与正确 alpha 显示的返图对照；白底查看图不是原始艺术文件。

API 使用 `gpt-image-2.5-sunburst`。只有实际收据里的请求算作一次调用；共画后的矩形裁片不重复记调用数。付费请求结果未知时，不自动重发。

原身体墨线保护蒙版用于约束 API 保留姿势；它不是最终画稿，也不保证模型严格遵守。必须对照源动作、手脚、钻发方位和连续性检查。相关接口与限制见[官方 OpenAI 文档](https://developers.openai.com/api/docs/guides/image-generation)。

旧稿、失败稿和请求记录均保留。技术完整性通过不等于造型/动作通过、用户验收或动态完成。
